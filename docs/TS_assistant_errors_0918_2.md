# TS — 2026-09-18 후반부 · 어시스턴트 오류 18건과 그 모양

작성자: 김준태(트랙 B) · 기록 대상: **어시스턴트 자신의 오류**
"고쳤다"가 아니라 **"어떻게 드러났나 / 무엇이 잡아줬나"** 를 적는다.

> **범위 주의.** `TS_assistant_errors_0918.md` 는 같은 사이클의 **전반부**
> (E2 folds · 실물 기하 · K 스윕 · `replay_trajectory`) 11건이다.
> 이 문서는 **후반부**(수집 선별 ~ 실데이터 첫 정책) 18건이고, **겹치지 않는다.**
> 두 문서를 합쳐 세면 29건이다. 한쪽만 보고 "하루에 11건"이라 쓰지 마라.

## 개수를 세 번 틀렸다 — 이게 첫 번째 기록 대상이다

```
세션 중 구두        "다섯 건"
KPT_0918 초판       11건
전 세션 재집계      18건
```

오류 개수는 **모수가 명시된 집계가 아니라 기억에서 나온 수**였다.
계측기 규칙(*모수를 같이 찍는다*)을 도구에는 걸어놓고 **내 자기보고에는 안 걸었다.**

→ **추가 규칙: 오류 개수는 세션 끝에 대화 전수를 훑어 센다. 기억으로 답하지 않는다.**

## A. 한 줄을 전체 맥락 없이 인용했다 — 4건

전반부 A 유형(잘린 범위)의 변종이다. 이번엔 범위가 아니라 **문장의 소속**을 틀렸다.

| # | 무엇 | 실제 | 무엇이 잡아줬나 |
|---|---|---|---|
| A1 | 0912 문서의 "대상물 규격 15~25mm" 를 **시연 물체 폭**으로 읽음 | 그건 **타겟 도메인 부품** 규격이다. 시연 물체는 41mm | 실측을 받고 G3 를 돌리니 차이 3.74mm 로 통과 |
| A2 | 체크포인트 하나 보고 *"문서의 action horizon 16 은 틀렸다"* 단정 | 시뮬 경로는 **진짜로 16**. 실 경로가 8 이다. 둘 다 맞다 | E1 cfg 재조회 |
| A3 | BE 문서 **예시 페이로드**의 `algorithm:"ACT"` 를 설정된 enum 으로 읽고 "ACT 전용" 기록 | 예시일 뿐. 디퓨전·공식모델로 가는 건 BE 도 인지 중 | 사용자 — *"act 알고리즘은 예시이고..."* |
| A4 | HW(현석) 답변을 트랙 A 답변으로 처리 | 3번은 도경(`AI/umi/**`), 4번은 은찬(BE 계약) 소관 | 소유권 표 재확인 |

**A1 의 방향이 특히 나쁘다.** 게이트 결과를 보기 전에 "불합격"으로 예측했고
**방향까지 반대**였다. 예측 참조집단을 잘못 잡은 게 아니라 **참조 대상 자체가 달랐다.**

→ **추가 규칙: 남의 문서에서 숫자를 가져올 때 그 숫자가 무엇을 재는 숫자인지
한 줄로 적는다.** "15~25mm" 가 아니라 "15~25mm(타겟 도메인 부품)".

## B. "전달됐다"를 확인 안 했다 — 2건

| # | 무엇 | 비용 |
|---|---|---|
| B1 | 파일 전송이 `{"written":[...]}` 성공인데 장비 파일은 구판. **총 4회** | 사용자가 **구판 계측기로 92편 전수를 한 번 더 돌렸다** |
| B2 | Jupyter 업로드를 지시 | 실제 경로는 커밋·푸시 |

B1 은 전형적인 **가용성 확인 != 기능 확인**이다. 반환값의 성공은 "요청이 받아들여졌다"
이지 "내용이 도착했다"가 아니다.

→ **규칙(이미 있음, 재확인): 전송 후 md5 로 대조한다. 재전송은 반드시 새로 stage 한 경로에서 한다.**
→ B2: **프로젝트 문서의 낡은 줄을 그대로 적용하지 않는다.** 경로가 바뀐 절차는
   사용자에게 한 줄로 확인한다.

## C. 판별력 0 인 검사를 만들었다 — 3건

**"없음"과 "괜찮음"이 같은 출력으로 나오는 검사는 검사가 아니다** — 이 프로젝트의
대표 실패형이 세 번 더 났다.

| # | 검사 | 왜 판별력이 0 인가 | 무엇이 잡아줬나 |
|---|---|---|---|
| C1 | `drops` | 첫 프레임 간격이 **항상** 공칭 2배(워밍업)라 92/92 전부 1 | **모수 출력** — 전편 동일값이라 상수인 게 보였다 |
| C2 | gap G1 초판 (Otsu 분리도 >= 2.0) | Otsu 는 **단봉도 무조건 둘로 쪼갠다**. 단봉 정규분포가 2.63 통과 | **합성 음성 표본 자체검증** (실데이터 전) |
| C3 | 프레임당 변위 속도로 30fps / 10Hz 판별 | 0.376 · 0.125 m/s **둘 다 사람 손 속도로 그럴듯하다** | 사용자가 30fps 를 확정해 줌 |

C2 는 **실데이터를 보기 전에** 잡혔다. 합성 음성 표본을 자체검증에 넣어둔 값이 여기서 나왔다.
C3 은 **가설 두 개를 다 통과시키는 검사**였다 — 애초에 만들지 말았어야 한다.

→ **추가 규칙: 검사를 만들기 전에 "이 검사가 기각할 수 있는 가설이 무엇인가"를 한 줄 적는다.**
   기각 대상이 안 적히면 그 검사는 만들지 않는다.

## D. 내 코드·실행 실수 — 5건

| # | 무엇 | 어떻게 드러났나 |
|---|---|---|
| D1 | `dist("raw_closed_marker_center_mm", ...)` 에 **`g_` 접두어 누락** → "값 없음 (n=0 / 92)" | **모수 출력.** `n=0 / 92` 라서 "필드가 없다"가 아니라 "내가 잘못 읽었다"로 읽혔다. `n=0` 만 찍혔으면 필드 부재로 결론냈을 것 |
| D2 | `--dataset` 에 zarr **디렉터리**를 넘김 | 로더가 `zarr.ZipStore` 라 `.zarr.zip` 필요. **E1·E2 가 전부 `.zarr.zip` 을 쓰는 걸 내가 보고도 그랬다** |
| D3 | v4.zarr 학습을 **홀드아웃 분할 없이** 띄움 | 76편 전부 train. 그 ckpt 로는 성능 측정 자체가 불가 — 학습이 다 끝나고서야 보임 |
| D4 | `[3b]` 자체검증 기대치 오기 — 4시그마 분리를 "겹친다"로 씀 | **자체검증 자신이 잡았다.** 1.5시그마로 수정하고 `[3c]` 에 "4시그마는 통과가 맞다"를 명시 |
| D5 | zarr gap 중앙 기대치를 **64.42mm** 로 제시 | 그건 92편 *편별중앙의 중앙*. 76편 **풀링 중앙은 61.60mm** — 내가 앞서 로컬에서 읽은 값과 정확히 일치했다 |

D1 이 이 문서에서 가장 값진 항목이다. **모수를 찍었기 때문에 같은 출력이
두 가지 원인을 구분했다.** C1 과 정확히 같은 장치가 반대 방향으로 작동했다.

D3 는 **비용이 가장 컸다** — 계산 시간을 통째로 버렸다.
→ **추가 규칙: 학습을 띄우기 전에 `provenance.json` 의 train/holdout 편수를 찍어 확인한다.**

D5 는 **집계 방식(편별중앙의 중앙 vs 풀링중앙)을 병기하지 않은 탓**이다.
→ **추가 규칙: 중앙값을 인용할 때 무엇의 중앙인지 적는다.**

## E. 판단·제안 오류 — 4건

| # | 무엇 | 무엇이 잡아줬나 |
|---|---|---|
| E1 | **2단계 전달 제안** — 비싼 단계(SLAM)가 아니라 싼 단계(v10 변환)에 게이트를 걸었다 | 사용자 — *"이건 진짜 왔다갔다 하는거잖아"* |
| E2 | **hand-eye 를 블로커라 불렀다** | `convert_v10_to_umi.py` 에 hand-eye 참조 **0건**. 적용은 도경 파이프라인 상류. `convert_real_umi.py` 는 별개 경로 |
| E3 | 사용자 다운로드 폴더의 **무관한 대용량 파일** 삭제 제안 | 사용자가 중지시킴 |
| E4 | v10 **입력** 규약을 모델 **출력** 규약으로 적어 BE 에 보낼 뻔 | 사용자 질문 한 줄 — *"이거 실제값 들어가지?"* |

E1 은 **최적화 방향 자체가 반대**였다. 왕복 비용을 비용으로 세지 않았다.
E2 는 "확인 안 한 것"을 "막고 있는 것"으로 올린 경우다 — **막힌 것과 안 본 것은 다르다.**
E3 은 삭제 규칙(*삭제 전 무엇을 지울지 보이고 검토받는다*)이 작동해서 막혔다.
E4 는 **결과적으로 값이 맞았다.** 그래도 오류다 — 근거 없이 적은 것과 근거를 대고
적은 것은 다르고, `rotvec` 을 거치는 경로가 있었으므로 **틀릴 수 있었다.**
