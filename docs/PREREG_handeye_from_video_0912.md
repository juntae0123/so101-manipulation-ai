# PREREG — hand-eye 를 영상에서 직접 실측한다 2026-09-12

작성자: 김준태(트랙B) · 이슈 S15P21A103-28, S15P21A103-31
도구: `tools/measure_handeye.py`

## 왜

HW 가 도면 기준 `T_S22camera→pinch` 를 줬다 🔵:
파지점 `(0, +24.6, +176.3)mm` (OpenCV 축), 광축 x 기준 105° 회전.

그런데 1프레임 대조에서 **Y 부호가 반대**였다 🟢 — 투영하면 화면 아래(v=725)인데
실제 그리퍼 마커는 화면 위(v=201)에 있다. 광축 180° 회전을 가정하면 잔차가 64.5→15.3mm 로 준다.

hand-eye 는 **상수 편향이라 학습이 지우지 못한다.** 실측 🟢 재생 위치 허용오차가
±5mm 4/4 · ±10mm 3/4 다. 부호가 틀리면 71편 전체가 무효다. 그리고 **파이프라인은 통과한다** —
손실은 잘 떨어지고 실물에서만 실패한다.

**주말이라 HW 회신을 기다릴 수 없다. 그런데 기다릴 필요도 없다** — 필요한 것이 영상에 다 있다:
매 프레임 마커 2개가 보이고, intrinsics 가 `episode.json` 에 있고, 마커 물리 간격이
gap 의 함수로 교정돼 있다 (37.6mm→gap 0 · 134mm→gap 70 🔵 황도경).

## 무엇을 재는가

**① 파지점 평행이동 (3 DOF) — 주 판정**

프레임마다 마커 두 개의 픽셀 중심과 픽셀 거리를 재고, 물리 간격을 알므로 깊이를 푼다.

```
dist_mm = 37.6 + gap_mm / 70 * (134 - 37.6)      (황도경 교정식 🔵)
Z = fx * dist_mm / dist_px
X = (u_mid - cx) * Z / fx      Y = (v_mid - cy) * Z / fy
```

마커 두 개는 턱에 좌우 대칭으로 붙어 있으므로 **중점이 그리퍼 중심선 위**다.
따라서 `(X, Y, Z)` 가 파지점의 카메라 좌표다 — 접근축 방향의 오프셋만 남는다 🟡.

gap 에 따라 손끝이 움직이므로 **gap 의 함수로 적합**한다 (HW 도 "176.3은 gap 8cm 기준"이라 했다).

**② 접근축 (회전 2 DOF) — 보조 🟡**

폐쇄 직전 구간에서 카메라가 물체 쪽으로 내려간다. 그 이동 방향을 카메라 좌표로 돌리면
접근축 추정이 된다.

```
d_cam = diag(1,-1,-1) @ R_GL(q)^T @ (p[t+1] - p[t])      (ARCore GL -> OpenCV)
```

마커축(턱 벌어지는 방향)과 접근축이 직교해야 하므로 그것으로 자기검사한다.
**나머지 1 DOF(마커축 기준 롤)는 이 방법으로 못 구한다 — 도면이 필요하다.**

## 조건

  그 도구는 도경 파일을 fixture 로 재현 검정했다 🟢 (중앙 0.346mm · 상관 0.999556)

## 사전등록 판정 (결과 전 확정)

**주 판정: 기준 gap 60mm 에서의 `(X, Y, Z)`**

| 조건 | 판정 |
|---|---|
| `\|X\| <= 5mm` 이고 편별 중앙값의 표준편차 `<= 5mm` | **마운트가 좌우 대칭이고 측정이 안정적이다.** 이 값을 hand-eye 평행이동으로 쓴다 |
| `\|X\| > 5mm` | 마운트가 비대칭이거나 검출이 편향됐다. 도면 없이 확정하지 않는다 |
| 편별 표준편차 `> 5mm` | 편마다 폰이 다시 장착됐거나 검출이 불안정하다. **±5mm 요구를 못 맞춘다** |

**보조 판정**

1. `Y < 0` 이면 → **HW 값의 부호가 뒤집혀 있다.** 180° 회전 가정이 맞다
2. `Y > 0` 이고 +24.6mm 에 가까우면 → 내 1프레임 대조가 틀렸다. 그 프레임을 다시 본다
3. `dZ/dgap` 의 크기가 **0.3mm/mm 를 넘으면** → 마커가 손끝에서 멀거나 턱이 크게 회전한다.
   그러면 단일 TCP 로 못 쓰고 gap 의존 TCP 가 필요하다
4. 접근축과 마커축의 사잇각이 **90±10°** 를 벗어나면 → 접근축 추정이 틀렸다. 그 절은 버린다
5. 편별 intrinsics 가 다르면 → 편마다 따로 풀어야 한다. 섞어서 적합하지 않는다

## 예측 (실행 전) 🟡

- `X` **−3 ~ +3mm** (1프레임 실측 −1.4mm). 마운트는 대칭일 것이다
- `Y` **−45 ~ −30mm** — **HW 값과 부호가 반대**일 것이다
- `Z` gap 60mm 에서 **140 ~ 160mm**
- `dZ/dgap` **0.3mm/mm 미만** — 마커가 턱에 붙어 있어 열고 닫아도 깊이는 거의 안 변한다
- 편별 표준편차 **3mm 미만** — 같은 장비로 연속 촬영이라 재장착이 없었을 것이다
- 접근축은 카메라 y-z 평면 안에 있을 것이다 (X≈0 이므로)

**크게 빗나갈 때**: 편별 표준편차가 5mm 를 넘으면 영상만으로는 ±5mm 를 못 맞춘다는 뜻이고,
그러면 HW 의 도면 실측이 **반드시** 필요하다. 그때는 이 측정을 "부호 확인" 용도로만 쓴다.

## 해석 제한

- **마커 중점이 파지점이라고 가정했다.** 접근축 방향 오프셋(손끝까지 얼마나 더 가는가)은
  이 방법으로 안 나온다 🟡. 도면이 있어야 확정된다
- **6 DOF 중 5 개만 구한다.** 마커축 기준 롤은 못 구한다
- 황도경의 gap 교정식(37.6/134)을 그대로 쓴다 🔵. 그 식이 틀리면 깊이가 비례해서 틀린다
- 검출 실패 프레임(내 도구 기준 15.4%)은 빠진다. 그 프레임들이 특정 자세에 몰려 있으면 편향이 생긴다
