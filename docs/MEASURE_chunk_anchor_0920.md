## 무엇을 재는가

`action[i, k]` 가 무엇을 기준으로 한 상대 변환인가. 두 해석이 경쟁했다.

```

앵커(B)   T0 @ A[k]                      k 가 몇이든 전부 청크 시작 기준
현행(C)   T0 @ A[lo] … @ A[k]            so101_infer.unroll 이 실제로 하던 것

```
