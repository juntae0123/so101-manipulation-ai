## 1. 현장 도착하면 **이것부터** — 매핑 편

⚠️ **시연 편보다 먼저 찍는다. 순서를 바꾸면 하루가 날아간다.**

```
map_atlas.osa      그 공간의 지도
tx_slam_tag.json   그 공간의 태그 → 월드 변환
```

둘 다 **촬영 장소에 묶여 있다.** 장소가 바뀌면 기존 것을 못 쓴다.
매핑 편 없이 시연 편만 찍어 오면 **SLAM 이 아예 안 돌아간다.**

- [ ] 태그를 테이블에 고정한다 (촬영 중 움직이면 전부 무효)
- [ ] 매핑 편 1편 촬영 — 태그가 계속 보이게, 공간을 천천히 훑는다
- [ ] 그 편으로 아틀라스와 `tx_slam_tag.json` 을 먼저 만든다
- [ ] **성공을 확인하고 나서** 시연 편 촬영 시작

⚠️ 매핑 편 촬영 방법(태그 배치·이동 경로·소요 시간)은 **도경 확인 대기**다.
답이 오기 전에 시연 편부터 찍지 마라.

## 2. 촬영 — 물리 조건

### 로봇이 못 따라가는 자세로 찍으면 전부 버린다 🟢

SO-101 도달 포락선 실측: **top-down(수직 구속)은 z 0.02~0.04 만 닿는다** (513칸 중 28칸).
**측면 파지만 재현 가능하다.** 평행 그리퍼 측면 파지는 접근축 둘레 회전이 자유라 5축으로 된다.

```
측면 파지 가능 영역 (베이스 원점, m)
    z = 0.027  →  x 0.37 ~ 0.46
    z = 0.051  →  x 0.34 ~ 0.46
```

- [ ] 물체를 그 범위 안에 놓는다. **위에서 덮어 잡지 않는다**
- [ ] 접근 방향을 편마다 바꾸지 않는다 (현석 성공 배치: y 폭 59mm · 회전 폭 0.127 rad)
- [ ] **시연자 한 명으로 고정한다.** 여러 명이 찍으면 회전 폭이 0.35 rad 를 넘는다
- [ ] 편당 2~5초. 손을 휘젓지 않는다 (목표 경로/직선 비 ≤ 2.5, 현석 1.63)
- [ ] 환경은 다양하게(조명·배경·물체 위치), 시연 방식은 동일하게
- [ ] **베이스 거치 높이를 재서 적어둔다.** 포락선 수치가 `base_height 0` 기준이다
- [ ] 동일 물체 1종 유지. 물체를 바꾸면 전문가 코드를 새로 써야 한다

## 3. SLAM — 도경 인계 구간

```bash

```

끝나면 게이트:

```bash

```

편당 **필수 10항목 + 권고 2항목**, 그리고 **배치 전체 1항목**.

**필수** — SLAM 품질: 궤적/그리퍼 판정 · 추적률 · 손실 구간 · 키프레임 · 마커 검출률 ·

**권고** — 시연 스타일: 편당 이동거리 · 카메라 궤적 범위

⚠️ **권고는 폐기 사유가 아니다.** 긴 궤적은 재현 난이도 경고일 뿐이고, 현석은
바로 그런 데이터(v4)로 학습에 성공했다. *"결과 모방이지 궤적 모방이 아니다."*
초판은 이걸 필수로 걸어 92편 전부를 떨어뜨렸다 — 이 프로젝트가 명시적으로
경고한 실수를 어시스턴트가 반복한 것이고, 2026-09-21 에 정정했다.

**실측 참조** 🟢 기존 92편에 걸어보면 **통과 67 · 불합격 25 (72.8%)**,
권고 경고 86/92. 현석 v4 채택률 76/92(82.6%) 와 같은 급이다.

⚠️ 배치 항목이 핵심이다 — **모든 편이 같은 `load_map_sha256` 를 써야 한다.**
서로 다른 아틀라스가 섞이면 좌표계가 섞이고, **그건 다른 어떤 지표에도 안 나타난다.**
섞였으면 불합격 편만 빼는 게 아니라 **전부 다시 돌린다.**

## 9. VLM (이슈 36 · 113)

### 절대 규칙

```
VLM  →  [돌릴까 / 말까] + [어느 ckpt]  →  정책  →  안전검사  →  로봇
        ↑ 여기까지만                      ↑ VLM 이 못 건드린다
```

**VLM 이 죽어도 로봇 경로는 그대로 돈다.** 이 조건이 아니면 붙이지 않는다.

### 붙이는 것 2개

**① 실행가능성 게이트** — 빈 책상이면 거절. 시연에서 허공을 집는 그림을 막는다.
**선행으로 경로 A 를 먼저 잰다** (공짜, 30분): 정책이 빈 장면에서 그리퍼를 안 닫는가.

```
입력   같은 책상·조명·카메라에서  물체 있음 30장 / 없음 30장
지표   한 관측당 예측 8스텝 중 gap 최소값 [mm]
게이트 without − with >= 20mm  → A 통과, VLM 불필요
       5~20mm                 → n 을 60/조건으로. 게이트를 낮추지 않는다
       < 5mm                  → A 미달, VLM 로 간다
선행검정 with/without 평균 화소차 >= 8/255 (아니면 "빈 장면"이 같은 그림이다)
정답행   with 조건 gap 중앙 < 50mm (물체 있는데 안 닫으면 배선이 틀린 것)
```

🟡 **예측: A 미달(0~5mm) 쪽에 건다.** 참조집단 — 어블레이션 2건이 전부
"이 파이프라인 모델들이 이미지를 생각보다 안 본다" 방향이었다.
한계: 둘 다 구 경로(BC·VLM)다. 현행 diffusion 은 다를 수 있다. **빗나가면 방향까지 기록한다.**

**② 스킬 선택기** — 자연어 + 장면 → 5스킬 중 선택.
5스킬 중 학습된 게 1개뿐이면 **나머지는 "미학습"으로 정직하게 표시한다.**

**③ 파지 대상 지정("빨간 거 집어" → 좌표)은 하지 않는다.** 정책 경로를 건드린다.

### 모델

실측 🟢 fp16 — SmolVLM2-500M **0.9961** / Qwen2.5-VL-3B **0.9909**
**SmolVLM2-500M 으로 간다.** 정확도가 높고 Jetson 8GB(이슈 42)에 들어간다. Qwen 백업.
