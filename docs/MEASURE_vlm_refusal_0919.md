### 거절 묶음별 — 예측이 맞은 곳 🟢
```
A(5종 밖 동작)   8 / 8     "커피 타 줘" "나사 조여 줘" …
C(모호·무의미)   9 / 9     "그거 해 줘" "알아서 잘" …
B(대상 없음)     1 / 8     "저기 있는 공 집어 줘" …
```
**세부 예측 A > C > B 는 적중했다.** B 가 최하인 것도 사전등록에 적은 대로다 —
**문장만으로는 장면을 모른다.** B 를 풀려면 이미지가 필요하고, 그게 ②/③의 경계다.

## 2. 예측 대조 — 크게 빗나갔다

| 대상 | 예측 (실행 전) | 실제 | 방향 |
|---|---|---|---|
| A 팔 판정 | G1 통과 · G2 미달 (0.35~0.60) | G1 0.72 · **G2 0.280** | 거절을 **과대**추정 |
| B 팔 판정 | G1 통과 · G2 미달 (0.30~0.55) | **G1 미달** · **G2 0.720** | **둘 다 반대** |
| A > B | A 가 약간 나을 것 | **B 가 거절에서 2.6배** | 빗나감 |
| 묶음 순서 | A > C > B | A 8/8 · C 9/9 · B 1/8 | **적중** |

**참조집단을 잘못 잡았다.** 0914 M1 의 Smol 관찰(*"프롬프트에 따라 몰빵 클래스만 바뀐다"*)을
근거로 "후보를 늘리면 잘 못 고를 것"으로 봤다. 실제로 Qwen 은 거절을 **너무 잘해서**
본업까지 거절로 삼켰다. 판별력이 있는 모델과 없는 모델을 같은 참조집단으로 쓴 것이 오류다.

## 3. 읽기 🟡

A(0.72 / 0.28)와 B(미달 / 0.72)는 **하나의 손잡이를 양 끝으로 돌린 모양**이다.
중간 어딘가에 쓸 만한 지점이 있을 수 있다 — A 의 퍼센타일을 올리거나 B 의 후보 문구를
약하게 하면 된다.

**지금 만지지 않는다.** 임계는 사전등록에 *"맞힌 항목 margin 하위 5퍼센타일"* 로 박았고,
결과를 보고 퍼센타일을 바꾸면 같은 데이터로 고르고 같은 데이터로 평가하는 것이다.
곡선(퍼센타일 ↔ 거절률)을 내려면 **새 사전등록**과 **분리된 평가 집합**이 먼저다.
