# 규칙 — 명령을 주기 전에 어시스턴트가 먼저 돌려본다 (2026-09-14 지적)

- 작성 계기: 사용자 지적 「왜 자꾸 시뮬하기 전에 뭐가 안 맞아서 여러 번 확인하냐,
  3주 하는데 아직도 최적화가 안 됐냐」
- 성격: **반복 실수. 재발 금지.**

## 무슨 일이 있었나 — 하루에 6건

| # | 실패 | 종류 |
|---|---|---|
| 1 | `scripts/train_bc.py` 로 썼는데 실제는 `tools/train_bc.py` | 경로 추측 |
| 2 | heredoc 안 `!!` 가 대화형 bash 에서 히스토리 확장 → 따옴표 파손 | 셸 동작 추측 |
| 3 | `bash -c` 안에서 `PY=` 를 export 안 해 자식 스크립트에서 빈 값 | 셸 동작 추측 |
| 4 | `sed` 치환 3건 중 2건만 매칭 (공백 수 차이) | 검증 없이 치환 |
| 5 | `Observation(**kw)` — `timestamp` 가 필수인 걸 모름 | API 추측 |
| 6 | `tail -n +27` 이 원본의 `set -eu` 를 잘라내 실패해도 계속 굴러감 | 부작용 미고려 |

**여섯 건이 전부 같은 종류다 — 확인할 수 있는 것을 확인하지 않고 썼다.**
프로젝트가 느린 게 아니라 명령 품질이 낮았다.

## 근본 원인

어시스턴트 쪽에 저장소가 없어서 **경로·시그니처·셸 동작을 전부 추측**했다.
그래서 사용자가 붙여넣어야 비로소 틀린 것이 드러났다. 왕복이 검증 수단이 되어 있었다.

## 해결 — 코드 사본을 어시스턴트 쪽에 둔다

```bash
# [서버]  데이터 제외, 코드만. 7.1MB
cd ~/S15P21A103
tar czf ~/ai_code_only.tgz \
  --exclude='*/datasets/*' --exclude='*/out/*' --exclude='*/runs/*' \
  --exclude='*.npz' --exclude='*.pt' --exclude='__pycache__' --exclude='.git' AI/
```

업로드하면 어시스턴트가 `torch`(CPU)·`mujoco` 를 깔고 **실제로 돌려본 뒤** 명령을 준다.
저장소 구조가 크게 바뀌면 다시 올린다.

## 명령을 내기 전 체크리스트

1. **경로** — `ls` 로 확인. `scripts/` 인지 `tools/` 인지 추측하지 않는다
2. **인자** — `python <도구> --help` 를 **어시스턴트 쪽에서 먼저 실행**한다
3. **API** — `dataclasses.fields()` · `inspect.signature()` 로 실제 시그니처를 본다
4. **문법** — `bash -n <스크립트>` · `python -c "import ast; ast.parse(...)"`
5. **셸 동작** — heredoc·따옴표·백그라운드는 로컬 bash 에서 그대로 한 번 돌려본다

## 셸 금지 목록 (전부 실제로 당한 것)

| 금지 | 이유 |
|---|---|
| 큰따옴표 안 `!!` | 대화형 bash 히스토리 확장. `set +H` 를 먼저 쓰거나 `**` 로 대체 |
| `bash -c` 안 비-export 변수 | 자식 스크립트에 안 넘어간다. `export` 를 붙인다 |
| `tail`·`sed` 로 스크립트 잘라 실행 | `set -eu` 같은 머리말이 잘린다. 잘랐으면 다시 넣는다 |
| 최상위 `set -e` / `exit` | 대화형 셸을 죽인다. `( )` 서브셸로 감싼다 |
| 꺾쇠 자리표시자 `<토큰>` | 셸 리다이렉션으로 해석된다 |
| 긴 heredoc | 붙여넣기가 절단·문자 유실된다. 파일로 쓰고 `-F` 로 넘긴다 |

## 일괄 스크립트 설계 규칙

- **스모크를 앞에 둔다.** 2편만 먼저 돌려 인자·경로·계약을 확인한다.
  2026-09-14 캠페인에서 이 단계가 계약 0.2.0 불일치를 **3시간 전에** 잡았다
- `set -eu` 를 넣어 **첫 실패에서 멈춘다**
- 치환(`sed`)을 했으면 **`grep -n` 으로 결과를 즉시 보인다**
- 파일을 지우지 않고 `_rejected/` 같은 곳으로 **옮긴다**

## 이 규칙이 못 잡는 것

- **데이터 규약 불일치** — 실행해야 안다 (계약 검증기가 거부해야 드러남).
  그래서 스모크 단계가 따로 필요하다
- **물리적 실행 불가** — 예: 지터 ±100mm 가 도달 영역 밖.
  이것도 스모크에서만 드러난다
