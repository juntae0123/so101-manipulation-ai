# PREREG — 현장 사진으로 VLM 장면 의존성을 잰다 (2026-09-21)

작성 김준태 (트랙 B) · **사진이 도착하기 전에 쓴다.** 이슈 S15P21A103-36, -109
계측기 `AI/tools/probe_vlm_scene.py` (자체검증 8/8, 모델·사진 없이 돈다)

## 무엇을 묻는가 — 거부율이 아니다

현재 선택 경로 `vlm/skill_choice.forced_choice_scores` 는 **강제선택**이다.
후보가 `SKILLS` 5개뿐이라 **"거부"라는 출력이 존재하지 않는다.** 🟢
"빈 장면에서 거부하는가"를 그대로 물으면 답은 재볼 것도 없이 0% 다.
**"재봤더니 0"과 "낼 수 없어서 0"은 다른 상태다.**

그래서 묻는 것은 **의존성**이다:

> 같은 지시문에 사진만 바꿨을 때, 점수가 달라지는가?

| 결과 | 뜻 | 다음 |
|---|---|---|
| 안 달라진다 | VLM 이 이미지를 안 본다. 스킬 선택은 지시문 분류일 뿐 | 빈 장면 거부는 **이 구조로 불가능**. 후보를 늘리거나(`probe_vlm_refusal`) 별도 판정기를 둔다 |
| 달라진다 | 이미지가 기여한다 | 그때 비로소 거부 임계를 논한다 |

## 수집할 사진 (현장 구현 때)

시연 영상과 **같은 카메라(S22) · 같은 거치 · 같은 조명**. 정지 사진.

```
empty_*      빈 작업대            30장
can_*        대상물 있음          30장
other_*      비슷한 크기·색의 다른 물체  10장   <- 판별행
occluded_*   대상물 절반 가림      10장
```

`other_` 가 판별행이다. **물체가 있기만 하면 반응하는지, 그 물체를 보는지**가 갈린다.

## 사전 등록 게이트 (사진 보기 전에 확정)

| 항목 | 기준 | 왜 |
|---|---|---|
| 묶음별 장수 | >= 10 | n 이 작으면 판정 못 한다. **게이트를 낮추지 말고 장수를 올린다** |
| 빈 장면 검정 `empty` vs `can` | 평균 \|화소차\| >= 2.0 | 같은 그림이면 "차이 없음"이 **공짜로** 나온다. 미달이면 **실행을 거부한다** |
| margin 중앙값 차이 | >= 0.02 | 이보다 작으면 이미지가 점수를 안 움직인 것 |
| argmax 분포 거리 (TV) | >= 0.10 | 최빈 스킬이 장면에 따라 바뀌는가 |

**넷 다 통과해야 PASS.** 하나라도 미판정이면 `INCOMPLETE` 이고, 미판정은 통과가 아니다.

## 예측 🟡 (사진 보기 전)

- **의존성 없음(FAIL)이 나온다고 본다.** 참조집단: M0 측정에서 `blank` 대조군이
  실물/렌더와 비슷한 성능을 냈다면 지시문만으로 푸는 것이고, 그 방향이 이어질 것이다.
  확률 감으로 7:3.
- margin 차이는 **0.00~0.02** 범위로 본다.
- `other_` 는 `can_` 과 거의 같게 나올 것으로 본다 (물체 종류를 구분하지 않는다).
- **PASS 가 나오면 내 판단이 틀린 것이고**, 그때는 거부 임계를 실제로 설계할 수 있다.
  빗나가면 방향까지 기록한다.

## 한계 — 먼저 말한다

- **강제선택 구조에서는 거부를 잴 수 없다.** 이 도구는 의존성만 잰다
- 지시문은 `INSTRUCTIONS` 에서 결정적으로 뽑는다. **그 문장들은 어시스턴트가 썼다**
  (실사용자 발화가 아니다) — 이미 문서에 적힌 한계이고 여기도 그대로 적용된다
- 사진은 정지 영상이다. 실제 추론은 시연 프레임에서 일어난다. **같다는 보장 없다**
- 조명·거치가 시연과 다르면 결과를 시연에 옮길 수 없다. 그래서 같은 조건을 요청했다
