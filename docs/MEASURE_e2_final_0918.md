## 4. 어디가 메워졌나 — 회전이다

`MEASURE_e2_A_noisefloor_0918.md` 에서 A조건의 구멍을 회전 일반화로 특정했다.

```
A  회전  train +20.6% / holdout -7.1%   ← 학습은 되는데 일반화가 안 된다
B  회전  holdout 5.26도 → 2.38도, identity 대비 +2.9%
```

**시뮬 사전학습이 정확히 그 구멍을 메웠다.** 병진·gap 도 같이 좋아졌지만
(개선폭 +21.7→+44.1%, +33.9→+54.9%), 부호가 뒤집힌 건 회전뿐이다.

### horizon별 병진 오차 (s0)

## 5. C조건이 말해주는 것

시뮬만 배운 정책은 **실 시연을 거의 못 맞힌다.**
```
병진  identity 대비 +3.2% (한 시드는 음수) — 사실상 동급
회전  -18.0%
gap   -259.1%   ← 오차 17~22mm
```

gap 이 무너진 이유는 명확하다. 시뮬은 **can 지름 67.8mm**, 실 시연은 **케이스 40mm** 다.
개폐 스케일 자체가 다르다. D-AI-52 에 적어둔 *"파인튜닝 효과와 도메인 차이를
분리할 수 없다"* 가 그대로 나타났다.

**이게 B 의 출발점이다.** 여기서 실데이터 60 epoch 를 더 돌려 위 결과가 나왔다.

## 6. 예측 대비 — 빗나갔다

D-AI-54 사전등록: 🟡 *"B 가 병진에서 A 를 이긴다 · 회전에서는 이기지만 identity 는
못 넘는다."* 참조집단 = "사전학습이 저수준 시각-운동 사상은 옮기지만 대상 도메인의
회전 분포는 옮기지 못하는 경우".

```
병진 A 를 이긴다              적중
회전 A 를 이긴다              적중
회전 identity 를 못 넘는다     빗나감 — s0 +4.9% · s2 +5.5% 로 넘었다 (s1 만 -1.6%)
```

**또 과소추정이다.** 2026-09-18 하루에 네 번 예측해 세 번을 낮게 잡았다
(E1, K=32 mean_K, 이번 E2). 방향이 한쪽으로 치우친다.

## 7. 한계 — 먼저 말한다

- **롤아웃이 아니다.** val_loss 0.00547→0.00517 에 롤아웃 0% 였던 전례가 있다.
  결론은 "홀드아웃 실 시연 예측 오차를 낮췄다" 까지다
- **실물 작업 성공으로 확대하지 않는다.** 시뮬 롤아웃 성공으로도 확대하지 않는다
- 홀드아웃 **13편**이다. 에피소드 단위 CI 의 n 이 13이다
- B조건 정책의 **관절각 사용 분포는 미측정**이다. 실 시연에는 대응하는 시뮬 태스크가
  없어 롤아웃 자체가 안 된다. 실물 평가가 복구됐으므로 이 빈칸은 실물 롤아웃으로 메운다
- 물체 한 종(케이스)이다. 다른 물체의 결론은 모른다
