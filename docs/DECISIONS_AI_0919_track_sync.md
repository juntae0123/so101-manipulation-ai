### jaw 보정 — 어댑터가 한 번만, 그리고 계측으로 정한다

도경 회신 원문 요지: *"jaw 방향 처리는 실제 IK 를 수행하는 어댑터에서 한 번만.

파지 여유 ±25mm 로는 확정적으로 빗나간다.

**조치 — 추측을 없애고 쟀다.** `policy_to_joints.probe_jaw_axis()`
```
prismatic 그리퍼 관절의 축 = 턱이 열리는 방향
그 축을 TCP 프레임으로 옮겨 TCP +X 와 이루는 각을 본다
  0도 근처   → 레거시 프레임. 92.789도를 한 번 넣는다
  92.79 근처 → ver1 프레임.  추가 회전 0도
  둘 다 아님 → 추측하지 않고 죽는다
사용자가 준 --jaw-offset-deg 가 계측과 다르면 거부한다 (이중 보정 차단)
```

## D-AI-70 · 5스킬 대상물을 실 시연 케이스 하나로 고정한다

**작성자**: 김준태(트랙 B) · **상태**: 확정 (협의 미성립분에 대한 단독 결정)
**성격**: 합의가 아니라 **결정**이다. 반대가 오면 되돌린다.

```
채택   실 시연 74편에 쓴 케이스 — 닫힘 gap 중앙 38.5mm [32.4, 43.5] n=69 🟢
기각   시뮬 YCB 토마토수프캔 ⌀67.8 × 101.8mm 349g
```

### 왜 캔이 아닌가 — 내 초판 제안을 뒤집는다

오늘 오전 현석이한테 보낼 초안에 *"5스킬 전부 원통 캔으로"* 라고 썼다. **틀렸다.**
캔은 **시뮬** 물체고, 실물에 올릴 정책은 그 물체를 배운 적이 없다.

결정적 근거 — 교사강제 측정 🟢:
```
정책 예측 gap   70.4 → 38.8 mm 까지 닫는다
기록           70.4 → 37.9 mm
```
**정책은 38.8mm 에서 멈춘다.** 캔(⌀67.8mm)을 놓으면 정책은 캔을 지나쳐 계속 오므린다.

그리고 이미 적혀 있던 한계였다 — `MEASURE_real_grasp_ik_0917` 한계 4번:
*"시뮬 캔(⌀67.8mm)으로 실 케이스(38.5mm) 시연을 평가했다. 턱 간격이 다르다."*
내가 쓴 문장을 내가 무시했다.

### 시뮬은 캔 그대로 둔다
시뮬은 warm start 용이고 이득이 trans 1~3mm 급이다(5-fold). 물체를 맞추자고
전문가 코드를 새로 쓸 값어치가 지금은 없다. 물체 불일치는 기록된 한계로 유지한다.

### 5스킬을 무엇으로 구분하나
물체는 공통, **차이는 [놓기] 단계에서만** 낸다. 구조상 이미 그렇다
(D-AI-22: 모든 스킬 = [집기 = 학습 정책] + [놓기 = 스크립트]).

### 남은 것
**케이스 실측 3축 치수 + 무게.** 도경 잠정 39mm, 우리 실측 gap 중앙 38.5mm —
±0.5mm 안에서 맞는다. 실물이 있으니 재면 된다. 받으면 레지스트리
`object_size_mm` 를 채운다 (지금은 빈 값 + validate 실패로 남겨뒀다).

### 되돌릴 조건
- 케이스로 시뮬 전문가 코드를 새로 써야 할 필요가 생기고, warm start 이득이
  그 비용을 넘는다는 측정이 나오면 재검토
- HW·PM 이 다른 대상물을 요구하면 그때 치수·무게를 받아 다시 정한다

**거절이라는 출력이 존재하지 않는다.** 지금 구조의 ③은 재볼 것도 없이 0%다.
"재봤더니 0" 과 "낼 수 없어서 0" 은 다른 상태다.

### 확정된 것 / 안 한 것
```

          ⚠️ 노드 배치는 [ROS] 47 · BE 소관. 트랙 B 가 정할 사안이 아니다
❌ 미측정  ② target grounding
```

### 인용 금지

### 되돌릴 조건

## D-AI-73 · 카메라 — 사양을 주지 않는다. 도메인 랜덤화로 간다

**작성자**: 김준태 · **상태**: 확정 (단독) · **통보 대상**: 김현석 · 황도경

```

a+2      13/20 =  65%   −35%p

z+5       8/20 =  40%   ·  z-5  15/20 = 75%
```

마운트 정밀도 문제가 아니라 **학습 데이터의 카메라가 하나뿐이라 생긴 과적합**이다.

### 기각한 안

### 채택
**B. 카메라 pose 도메인 랜덤화 재학습.** 사전등록 `PREREG_domain_randomization_0919`.

⚠️ 도메인 랜덤화는 트랙 A(황도경) 소관이다. **AI 안이라 단독 결정하되 통보한다.**
