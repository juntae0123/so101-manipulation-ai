`check_collection_quality.py` 는 그 축을 재지 않는다.

→ **LIMITS 등재 대상.** 수집 품질 검사만으로는 SLAM 성공을 예측할 수 없다.

## 2. 내일 수집에 직접 걸리는 계수

```
수집 N 편  →  품질검사 통과 약 0.98N  →  SLAM pass 약 0.90x(그 값)  →  약 0.88N
```
0918 실측: 92 → 90 → 81. **필요 편수가 N 이면 N/0.88 을 찍어야 한다.**
⚠️ 계수는 **이 한 배치의 관측값**이다. 환경이 바뀌면 SLAM 통과율이 먼저 바뀐다.

## 7. 어시스턴트 오류

`dist("raw_closed_marker_center_mm", ...)` 에서 `g_` 접두어를 빠뜨려
`값 없음 (n=0 / 92)` 이 나왔다. **모수를 같이 찍었기 때문에** "그 필드가 없다"가 아니라
"내가 잘못 읽었다"로 읽혔다.
**조치**: 자체검증 `[6]` 추가 — `dist()` 호출의 그리퍼 키에 `g_` 가 없으면 계측기가 먼저 죽는다.
