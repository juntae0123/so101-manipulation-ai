## 1. 롤아웃 🟢

학습 시드 0·1·2 · 평가 시드 3000~3099 · `offsamples 0`

| 타깃 | val (시드별) | 롤아웃 | 95% 구간 |
|---|---|---:|---|
| `state[t+1]` (계약) | — | 0/300 = 0.0% | [0.0, 1.3] |
| **`state[t+2]`** | 0.195 / 0.268 / 0.196 | **0/300 = 0.0%** | **[0.0, 1.3]** |

사전등록 게이트 G2(어떤 k 의 하한 ≥ command 하한 4.9%) **미달.**

⚠️ **val loss 가 오히려 2~3배 높은데 롤아웃은 0 이다.** "타깃을 어렵게 만들면
학습된다"가 아니라는 직접 증거다. 리드를 처방으로 본 전제가 틀렸다.

**lead8 은 돌리지 않았다** — 게인 8배라 음성이 나와도 읽을 수 없다.

## 2. 데이터 수준 프로브는 이 건을 못 갈랐다 🔴

같은 데이터, 기준선만 바꿨더니 정반대가 나왔다.

| 타깃 | 설명력(1스텝 기준선) | 설명력(k스텝 기준선) |
|---|---:|---:|
| `state[t+1]` | 87.4% | 87.4% |
| `state[t+2]` | 48.1% | 88.4% |
| `state[t+4]` | 24.4% | 84.4% |
| `state[t+8]` | 12.2% | 75.3% |
| `state[t+16]` | 6.3% | 54.6% |
| `ctrl` | 67.0% | 17.9% |

- **1스텝 기준선**: k 가 커질수록 기준선이 무너진다 (k=16 에서 외삽잔차/크기 93.7%).
  낙폭이 부풀려져 전부 G1 통과로 보인다
- **k스텝 기준선**: 정책이 실제로 못 쓰는 정보다. 정책은 `use_state` 단일 프레임이라
  `s[t]-s[t-1]` 을 계산할 수 없다. 기준선이 너무 강해 전부 G1 미달

**둘 다 방어 가능하고 답이 반대다. 데이터 통계로는 못 가른다.**

결정적 반례도 있다 — `ctrl` 크기 0.00316 < `lead1` 크기 0.00356 인데 `ctrl` 만
학습된다. **타깃 크기도 설명력도 단독으로는 롤아웃을 예측하지 못한다.**

## 3. 내 설계 결함 🔴 (외부 검토에서 지적받음)

```
action_space = joint_delta_gripper_binary
to_action:    action = state + residual      1틱 목표로 나간다
lead-k 타깃:  state[t+k] - state[t]          k틱 걸릴 변위
```

**k틱 갈 거리를 1틱 목표로 보낸다. 게인이 k배다.** 타깃만 바꾼 비교가 아니라
제어 게인을 같이 바꾼 비교였다. `ctrl`·`lead1` 은 1틱 신호라 의미가 맞고
`lead2` 이상만 안 맞는다.

⚠️ **따라서 lead2 의 0/300 은 "리드가 무용하다"의 증거로 단독 인용하면 안 된다.**
게인 교란과 타깃 성질을 가르지 못한다. 방향이 k스텝 외삽 계측과 일치할 뿐이다.

**그리고 이 결함을 제대로 고치면 그것이 행동 청킹이다** — k스텝을 예측하고
k스텝에 걸쳐 실행하면 게인이 안 바뀐다. 즉 lead-k 는 청킹의 열등한 형태였다.
**170 의 남은 질문은 S15P21A103-171 이 흡수한다.**
