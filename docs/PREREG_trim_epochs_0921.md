## 왜

첫 학습 결과 `beats_hold_baseline: false` · 위치 RMSE 배수 **0.52x** (정책이 hold 보다

## 예측 🟡 (결과 보기 전)

- **R1 < 1.0x.** 참조집단은 R0(0.52x). 8 epoch 은 데이터와 무관하게 수렴 전이라고 본다.
  범위 0.4~0.9x. **R1 ≥ 1.0x 면 내 판단이 틀린 것이고, epoch 이 아니라 trim 이
  지배적이었다는 뜻이다.**
- **R2 = 2.0~3.5x.** 참조집단은 현석 s22_pick_v3(3.12x, 같은 트레이너·profile).
  우리는 10편이고 현석은 그보다 많으므로 **그 아래**로 본다.
  R2 < 1.0x 면 데이터나 파이프라인에 trim 말고 다른 문제가 있다는 신호다.
- R1 -> R2 상승폭이 R0 -> R1 상승폭보다 **크다**고 본다 (epoch 이 더 지배적).

빗나가면 **방향까지** 기록한다.
