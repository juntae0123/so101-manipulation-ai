**우리 숫자는 우리 검출기의 하한이지 정본이 아니다.** 2026-09-12 대조 🟢 (같은 71편):

## 5. 어시스턴트 오류 2건

### 5.1 `drops` 가 92/92 전부 1 — 판별력 0

```
공칭 frame_duration_ns 33333333 · 간격 중앙 33331302
1.5x 초과 간격 [(0, 66662656)]  ← index 0 하나뿐, 정확히 2배

```
첫 간격이 항상 공칭 2배다(카메라 워밍업). 전 편 공통이라 "드롭 없음"과 "있음"이 같은 출력이었다.
**조치**: 첫 간격 제외, `first_gap_ratio` 로 분리 보고. 자체검증에 `[5b]` `[5c]` 추가.
수정 후 **진짜 드롭 0건**, `first_gap_ratio` 92편 전부 2.00.

### 5.2 파일 전송 성공 응답을 내용 반영으로 읽었다

패치본 전송이 `{"written":[...]}` 로 성공이었는데 장비 파일은 구판이었다
(13398바이트 vs 14911바이트). 사용자가 구판으로 한 번 더 전수 실행했다.
**조치**: 다른 경로로 재전송 후 해시 대조. 이후 전송은 응답이 아니라 해시로 확인한다.
