## D-AI-47 (제안) — 계약에 `command` 필드를 추가한다

**작성** 김준태(트랙 B) · **합의 필요** 황도경(트랙 A)

### 무엇을

```
action    (6,) float32   계약 그대로 state[t+1] 유지 — 검증기·기존 데이터 호환
command   (6,) float32   신설. 내린 명령 / 목표 자세. 학습은 이쪽을 타깃으로 쓴다
```

`action` 의 정의와 `validate()` 의 `action[:-1] == state[1:]` 검사는 **그대로 둔다.**

### 왜

계약 0.3.0 의 `action[t] = state[t+1]` 은 **"이미 간 거리"** 다. 30Hz 에서 그것은
관측 없이 87~94% 예측되고, 롤아웃에서 정지가 고정점이 되어 **팔이 움직이지 않는다.**

같은 데이터 59편에서 타깃만 바꿔 독립 학습 3회 × n=100 으로 측정했다 🟢.

| | `action = state[t+1]` | `command = ctrl` |
|---|---:|---:|
| 성공률 | **0/300 = 0.0%** [0.0, 1.3] | **22/300 = 7.3%** [4.9, 10.9] |
| 닫는 순간 | 158.1 / 158.4 / 158.3mm | 45.2 / 42.5 / 48.8mm |

조건: MuJoCo 3.12.0 EGL · 30Hz · 2cm 20g 큐브 · 지터 ±50mm · `cam_wrist` 1대 ·
`joint_delta_gripper_binary` · 학습 시드 0·1·2 · 평가 시드 3000~3099

두 분포가 겹치지 않는다. 그리고 158mm 는 **다섯 조건에서 폭 0.4mm 로 재현**됐다.

### 왜 `action` 을 되돌리지 않고 필드를 더하나

| 안 | 대가 |
|---|---|
| `action` 정의를 되돌린다 | **수집분 전부 무효.** 검증기·변환기·기존 체크포인트 전부 영향 |
| **`command` 를 더한다** | 기존 데이터 안 깨짐. 다만 **기존 수집분은 `command` 가 비어 있다** |

기존 수집분은 재수집하거나 역산해야 한다. 시뮬은 재수집이 싸다(60편 45초).
**실수집 UMI 는 트랙 A 확인이 필요하다** — 원본 raw 에 목표 pose 계열이
남아 있으면 역산이 가능하고, 없으면 재수집이다.

### 실물에서 `command` 는 무엇인가

시뮬에서는 `data.ctrl` 이다. 실물 대응물은 **미확정**이며 트랙 A·MW 확인 사항이다.

후보 🟡 — UMI raw 의 EEF 목표 pose 계열, 또는 IK 입력으로 들어간 목표 자세.
`ctrl − qpos` 에 해당하는 "가려는 곳 − 지금 있는 곳" 이 나오는 값이면 된다.

⚠️ **없으면 이 결정은 시뮬에만 적용되고 실데이터는 별도 설계가 필요하다.**

### 되돌릴 조건

- 실물에 `command` 대응물이 없고 역산도 불가능하면 → 이 결정을 폐기하고
  액션 표현 자체를 재설계한다 (ACT 의 action chunking 이 대안)
- `command` 로 학습해도 게이트 20% 를 못 넘는 상태가 지속되면 →
  필드는 유지하되 "이것으로 충분하다"는 주장은 철회한다

### 이 결정이 답하지 않는 것

- **게이트 20% 를 넘는 방법.** 7.3% 는 한참 미달이다.
  원인 하나를 제거한 것이지 문제를 푼 것이 아니다
- **실물 성능.** 전부 시뮬이고, 시뮬 성공률은 sim2real 갭의 하한이다
- 스크립트 시연 특유일 가능성 🟡 — `ctrl` 이 웨이포인트 사이에서 계단 함수라
  `command` 타깃도 `shoulder_pan` 58% · `wrist_roll` 70% 가 정확히 0 이다.
  사람 시연에서는 다를 수 있다

## 부수 기록

### L-신규 — `sim_pick_v5` 는 `sim_pick_v3` 와 내용이 같다 🟢

여섯 키(`state`·`action`·두 타임스탬프·두 이미지) 전부 해시 동일.
파일 sha256 은 달라 보이지만 npz 가 zip 이라 엔트리 메타데이터 때문이다.

**"v5로 측정"이라고 적힌 과거 수치는 v3 와 같은 데이터다. 독립 표본으로 인용하지 않는다.**

### L-신규 — npz 파일 해시는 내용 해시가 아니다 🟢

같은 배열이라도 zip 메타데이터 때문에 파일 해시가 달라진다.
데이터셋 동일성 확인은 **키별 배열 해시**로 한다.

### L-신규 — 물체를 ±50mm 넘게 옮기면 SO-101 이 도달하지 못한다 🟢

기준점 x=0.22, 도달 영역 x[0.10, 0.25]. ±100mm 스모크 2편 전부 도달 불가.
재수집 프로토콜의 물체 배치 범위에 이 값이 들어가야 한다.

### REJECTED — 제어주기 다운샘플 (30→10Hz)

외삽 설명력 낙폭 12.1%p, 사전등록 게이트 15%p 미달. 🟢

### REJECTED — 물체 위치 변주 확대

j0/j25/j50 설명력 낙폭 0.6%p, 롤아웃 세 조건 전부 0/300. 🟢
