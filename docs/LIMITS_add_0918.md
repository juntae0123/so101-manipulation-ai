선별기는 동기화·IMU·길이·마커를 보지만 **"SLAM 이 붙을 만한 화면인가"는 못 본다.**

**(나) 미검출 구간의 *위치* 를 기록하지 않았다** 🟢

**(다) 우리 마커 검출률과 도경 파이프라인 검출률이 같다는 근거가 없다** 🟡

## 재현성

**(라) `--deterministic` 미적용** 🟢

`run_folds_0918.sh` 는 `--seed 0` 만 고정한다. **cuDNN 까지 덮지 않으면 시드 고정이
재현을 보장하지 않는다** — 이 프로젝트에 이미 기록된 함정이다.
따라서 5-fold 의 fold 간 분산에는 **분할 차이 + 학습 비결정성이 섞여 있다.**

→ 해소: 같은 분할시드로 학습만 2회 반복해 비결정성 성분을 따로 잰다. 미실행.

**(마) 재현 대조 규약 (가)(나) 는 미검증 예상이다** 🟡

`camera0_rgb` 비트 일치(리사이즈·디코더 차이)와 부동소수 비트 일치(numpy/scipy/BLAS
빌드 차이)가 실제로 어긋나는지는 **기준 산출물이 와야 안다.**
검사기는 어긋날 경우를 감당하게 설계했으나 **실제로 어긋나는지는 아직 모른다.**

→ 현석 확인 필요.

**(차) 학습 79편이 두 수집 세션에 쪼개져 있다** 🟢

18편 / 72편(선별 전 기준)으로 갈린다. **세션 간 분포차를 측정하지 않았다.**
층화 없이 무작위 분할하면 holdout 이 한쪽 세션에 쏠릴 수 있다.

→ 해소: 분할 시 세션 층화, 또는 세션별 holdout 성능을 따로 보고.

v10 원본의 `source_row` 간격이 불균일하다(2 와 3 혼재). **0.1초 고정 가정 금지.**
실제 시각은 `observation_timestamp` 에 있다. 계약에 "공칭"으로 적었다.
