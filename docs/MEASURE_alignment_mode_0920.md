
⚠️ **표본 3편이다.** 같은 앵커식으로 10편을 잰 0919 재현값은 **78/90 = 86.7%** 이고

양성 대조를 먼저 돌렸고, 앵커 정렬에서 27/27 이 나왔으므로 **계측기는 정상이다.**

자세오차 분해에서 자유축이 0.0도라 5도 임계가 무해한 회전을 거부한 것도 아니다.

## 해석

두 정렬은 다른 것을 고정한다.

```
grasp 앵커      파지점을 도달권 안 한 점에 놓고 나머지를 역산한다.
                T_align(p, yaw) = Trans(p) @ Rz(yaw) @ Trans(-g)
                → 파지 순간이 반드시 도달권에 든다. 대신 파지점을 미리 알아야 한다

episode-start   시연 시작 TCP 를 로봇 홈에 맞추고 상대 델타를 쌓는다.
                → 파지점이 어디로 갈지는 시연이 정한다. 실시간 실행이 이 방식이다
```

**실물 폐루프는 episode-start 밖에 쓸 수 없다.** 파지점을 미리 모르기 때문이다
(`T_base_tcp_target = T_base_tcp_current @ A_relative`, D-AI-67 · 황도경 확인).

회전 잔차 29~33도가 핵심이다. 사람이 UMI 리그를 손에 들 때 **시작 자세가 매번
임의**인데 로봇 홈 자세는 고정이다. episode-start 는 그 차이를 처음부터 안고 가고,
상대 델타를 쌓을수록 누적된다.

### ⚠️ 원인으로 확정하지 않는다 (황도경 지적, 2026-09-20)

이 실험은 **시뮬 recorded-action IK** 다. 로봇 장착 hand-eye 를 직접 쓰지 않는다.
따라서 hand-eye 를 원인으로 지목할 수 없다. 아래 다섯을 **분리해서** 확인해야 한다.

```
① 시작 6DoF 불일치      시연 시작 자세 vs 로봇 홈 자세
② relative 합성 구현     rot6d 행/열 · T@A vs A@T · 적용 프레임
③ demo-rig TCP 원점      provisional. 마커 중점 = 패드 중심 직접 증거 없음
④ 로봇 장착 hand-eye     미측정. 이 실험에는 안 들어간다
⑤ IK branch 선택         wrist-roll 후보 중 어느 해를 고르는가
```

이 측정이 좁힌 것은 "**정렬 방식이 결과를 가른다**" 까지다. 그 안의 원인은 미분리다.

**회전이 일관된 병목이다.** 정렬을 바꿔도 남는다 —
0919 앵커 정렬 재현에서 거부 12/12 가 전부 `rotation_residual` 이었고,
오늘 episode-start 에서는 회전 잔차가 29~33도로 커졌다.
위치가 먼저 걸려 사유에는 `position_residual` 만 찍혔을 뿐이다.

이는 현석 실물 로그와 같은 구조다 🟢 — 청크 안에서 `approach_error_deg` 가
0.5 → 3.6도로 커지고 `wrist_flex` 가 하한에 박힌 뒤 `wrist_roll` 이 337틱(-150.4도)으로
브랜치 점프했다.
