## 2. BC 계열 처방이 소진됐다

```
제어주기 다운샘플 30->10Hz    기각 (낙폭 12.1%p, 게이트 15%p 미달)
물체 위치 변주 확대            기각 (낙폭 0.6%p, 세 조건 전부 0/300)
액션 타깃 리드 state[t+k]      기각 (0/300, 게인 교란 있음)
행동 청킹 K=2/4/8/16           기각 (구간 전부 중첩)
액션 정의 ctrl                 효과 있음 0% -> 8~13%. 게이트 20% 는 미달
```

**모델을 더 바꾸는 것은 여기서 멈춘다.** 다음 가설은 데이터다.

```
scripted (정답 위치 사용)   84%                          태스크는 풀린다
학습 정책 최고              13.3%                        위치 추정 비용 70%p
DAgger 손목전용             51.4% [47.0, 55.8] n=500 🟢
```

같은 씬·같은 카메라 1대인데 13.3% 와 51.4% 다. **차이는 수집 방식뿐이다.**

⚠️ DAgger 데이터는 계약 0.2.0 이라 현행 로더가 거부한다. 0.3.0 + `command` 사이드카
재수집이 필요한지 확인이 선행이다.

## 2. ⚠️ 사이클 1 결론 정정 2건

### ① "행동 청킹은 처방이 아니다" — 조건부로 정정

사이클 1 에서 K=2/4/8/16 구간이 전부 겹쳐 기각했다. **그 판정은 전문가 데이터
한정으로만 유효하다.** 혼합 데이터에서는 K=1 0.3% → K=8 63.7% 로 결정적이다.

정정된 문장: **"전문가 시연만으로는 청킹이 처방이 아니다. 혼합 데이터에서는 청킹이
없으면 혼합의 효과가 나오지 않는다."** 가산 효과가 아니라 **상호작용**이다.

### ② "BC 계열 처방이 소진됐다 / 다음 가설은 데이터다"

방향은 맞았다. 다만 기제는 "데이터만 바꾸면 된다" 가 아니었다.
혼합 단독 0.3%, 청킹 단독 8.0%. **데이터와 실행 방식을 같이 바꿔야 났다.**

### ③ 계약 `action` 은 죽은 타깃이 아니라 약한 타깃

0914 "계약 action 은 학습을 무력화한다" → 혼합+K=8 에서 7.7% [5.2, 11.2].
정정: **"전문가 데이터 + K=1 조건에서 0% 다."**
D-AI-47 근거는 유지 (63.7% vs 7.7%, 구간 비중첩).

### ⚠️ `(N,2)` 합의했는데 축 의미가 서로 달랐다

```
내 근거     축1 = 카메라 2대의 캡처 시각   <- 틀렸다. 계약 0.3.0 은 cam_wrist 1대

```

같은 shape 에 다른 의미. 이대로 두면 축을 반대로 읽고 **조용히 틀린다.**

```

## 7. K 스윕 결과 — K=8 확정 🟢

```
