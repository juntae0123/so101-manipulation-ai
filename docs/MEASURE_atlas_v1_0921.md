## atlas 튜닝이 고친 것과 안 고친 것

같은 금요일 원본인데 회전 폭이 커졌다 (**0.519 -> 0.749 rad**).
아틀라스 공유는 **지도 일관성**을 고치는 것이지 시연 궤적을 짧게 만들지 않는다.
경로/직선 2.89 도 s22_pick_v3 의 1.63 로 안 내려왔다.

→ **궤적 크기는 촬영으로만 줄어든다.** 재촬영이 41% 개선이었다는 앞선 측정과 같은 방향이다.
→ 내일 촬영 지침: s22_pick_v3 처럼 **짧게**. 편당 2.4~4.6초, 경로/직선 1.6대 목표.

- **학습은 아직 안 돌렸다.** 위는 전부 데이터 계약·기하이고 정책 성능이 아니다
