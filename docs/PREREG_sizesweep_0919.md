# PREREG — 2026-09-19 · 학습 편수 대 시뮬 사전학습 이득 (착수 전 기록)

작성 김준태(트랙 B) · **이 문서는 실행 전에 쓴다. 결과를 보고 고치지 않는다.**

## 왜

0919 5-fold 에서 warm start 이득이 E2 대비 1/5~1/13 로 줄었다
(`MEASURE_folds_real_0919.md` §4). 원인 가설은 **A 조건이 더 이상 불리하지 않아서**다 —
도경의 축 수정으로 실데이터만 학습한 정책이 좋아졌다.

그 가설이 맞으면 **A 를 다시 불리하게 만들면 이득이 커져야 한다.**
데이터를 줄이는 것이 그 방법이고, **월요일 현장 재학습이 정확히 그 상황**이다
(현장에서 20편쯤 찍고 재학습). 지금 재두면 월요일에 warm start 를 쓸지 말지가 정해진다.

## 설계

```
홀드아웃   고정. ds_f0918_42_holdout.zarr.zip (14편 816표본, identity trans 71.422mm)
           ⚠️ 홀드아웃을 고정해야 N 끼리 비교된다. 바뀌면 기준선이 같이 움직인다
학습편수   N = 20 / 40 / 60      (seed 42 train zarr 앞에서 잘라 **중첩** 부분집합)
조건       A = warm start 없음 · B = outputs/e2_C/checkpoints/latest.ckpt 에서 출발
공통       60 epoch · batch 8 · seed 0 · action_horizon 8 · obs_down_sample 1
재사용     N=60 은 f0918_A_42 / f0918_B_42 가 이미 있다. 새로 돌리는 건 4개
```

### 이 설계가 못 자르는 것 — 먼저 적는다

- **에폭 고정이라 N 이 작으면 총 스텝도 줄어든다.** "데이터가 적어서"와 "학습을 덜 해서"가
  섞인다. 실무 질문이 *"현장에서 20편 찍고 같은 레시피로 돌리면?"* 이라 이걸 골랐다.
  스텝 수를 같이 기록해서 나중에 귀속할 수 있게 한다
- **부분집합이 한 번의 뽑기다.** 앞 N 편을 자르므로 중첩(20 ⊂ 40 ⊂ 60)은 보장되지만
  그 20편이 대표적인지는 모른다. 0918 수집분은 세션이 둘로 갈렸던 전례가 있다 —
  **편 구성을 출력해서 쏠림을 사후 확인한다**
- **오프라인 궤적 오차다. 롤아웃이 아니다.** val 이 내려가도 롤아웃 0% 였던 전례가 있다

## 게이트 — 결과 보기 전에 박는다

```
G1  N=20 에서 B−A 병진의 95% CI 가 0 을 포함하지 않는다
G2  |B−A| 병진이 N=20 에서 N=60 보다 **2.0mm 이상** 더 크다
```

**G2 의 2.0mm 가 사전등록한 최소 의미 효과크기다.** 0919 에 부호만 박고 크기를 안 박아서
"통과했는데 실무적으로 의미 있나"를 못 말했다. 이번엔 박는다.

```
G1·G2 둘 다 통과   → 데이터가 적을수록 warm start 가 중요하다. 월요일 현장 재학습은 B 로 간다
G1 만 통과         → 도움은 되지만 편수와 무관하다. B 로 가되 이득을 기대하지 않는다
G1 실패            → n=1 부분집합으로는 못 가른다. 게이트를 낮추지 말고 뽑기를 늘린다
```

## 예측 🟡 — 참조집단 명시

**참조집단**: "A 조건이 불리해지면 B−A 가 커진다"는 0918→0919 관측.
축 수정 **전** A 가 불리했을 때 B−A 는 −8~−12mm, 수정 **후** −0.5~−2.8mm 였다.
데이터 부족도 A 를 불리하게 만드는 축이므로 같은 방향을 예상한다.

```
G1  통과한다
G2  통과한다
B−A 병진 N=20   −3 ~ −8 mm
A 단독 N=20     N=60(22.124mm) 보다 3mm 이상 나쁘다
```

⚠️ 이 참조집단은 **조건이 다른 실험**이다(축 수정 유무 vs 편수). 0919 에 같은 실수로
과대추정했다. 빗나가면 방향까지 기록하고 이 참조집단을 다시 쓰지 않는다.
