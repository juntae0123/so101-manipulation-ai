## L-- 시연 생성기가 물체 전용이다 🟢
`run_side_expert` 는 물체 **위치**는 따라가지만 **크기·높이**는 못 따라간다.
잡는 높이 = 물체 중심(하드코딩), 대기 지점 = 50mm 뒤(고정).
박스(높이 50mm, 중심 25mm)에서 0/60 — 물체 이동량 정확히 0.0000,
양측접촉 False, normal_force 0.34 N. 그리퍼가 닿지도 않았다.
→ **5스킬 물체 선정 시 전문가 코드를 물체마다 새로 써야 한다. HW·PM 확인 필요.**
→ 타겟 도메인(D-AI-19 소형부품)은 대체로 낮아서 이 시뮬 자산으로 시연 불가.
근거: `MEASURE_task2_envelope_0916.md` §4, §7

## L-- env.ik 의 통과 기준이 자세 오차에 느슨하다 🟡
`residual < 0.008` 에서 회전 항 가중치가 0.08 이라 **자세 오차 0.1rad(5.7°)까지
통과**한다. y 가 커질수록 필요한 회전이 커지고 파지가 빗나가는 것으로 보인다
(y=0.14 에서 1/5, `lift_m 0.0103`, 한쪽 패드만 접촉).
**미검증** — 자세 오차와 실패를 직접 짝지어 재지 않았다.
