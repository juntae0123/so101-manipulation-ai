## D-AI-52 · E2 실험 프로토콜

**작성자**: 김준태(트랙 B) · **트랙 A(황도경) 합의됨**
**상태**: 확정

### 무엇을 재나
**"시뮬 사전학습이 실 시연 학습을 돕는가"** 를 **홀드아웃 실데이터의 상대 action chunk
예측 오차**로 판정한다. 시뮬 롤아웃으로 판정하지 않는다.

시뮬 롤아웃을 쓰지 않는 이유 — 실 시연의 물체 위치가 명시적 라벨로 남아 있지 않고,
실 영상과 MuJoCo 렌더의 도메인이 달라 **파인튜닝 효과와 도메인 차이를 분리할 수 없다.**

### 세 조건

| | 학습 | 데이터 | down_sample | 표본 |
|---|---|---|---|---|
| **A** | 실 UMI 만 | `ds_real.zarr.zip` | **1** (이미 10Hz) | 10Hz |
| **B** | 시뮬 사전학습 → 실 UMI 파인튜닝 | C 체크포인트 + `ds_real` | 1 | 10Hz |
| **C** | 시뮬만 | `ds_6000.zarr.zip` (30Hz) | **3** | 10Hz |

공통: `action_horizon=8` = **0.8초** · 관측 history 2 · 60 epoch · batch 8 · 학습 시드 0/1/2

⚠️ **조건마다 `obs_down_sample_steps` 가 다르다.** 실데이터 zarr 은 이미 10Hz 라
3으로 두면 3.33Hz 가 되고 18프레임 에피소드에서 horizon 을 못 만든다.
**같은 물리 시간(0.8초)을 맞추기 위해 다른 값을 쓴다.**

### 분할
```
69편 → 학습 55 / 홀드아웃 14   (에피소드 단위 · split_seed 42 고정)
ds_real.split.json 에 편 이름까지 기록
```
- **학습 시드가 바뀌어도 분할은 안 바뀐다**
- 홀드아웃 14편은 early stopping·모델 선택·하이퍼파라미터 조정에 쓰지 않는다
- 원본 70편 중 1편(`rec_20260911_145625`)은 행이 1개라 복원 검증이 불가능해 제외

### 지표 (트랙 A 명세)
표준화 L1 만 쓰지 않고 물리 단위를 병기한다.
```
translation L2 [mm] · rotation geodesic [deg] · gap MAE [mm]
horizon 1~8 별 오차 · 8-step chunk 전체 오차
identity 기준 대비 개선율
  identity = translation 0 · rotation 항등 · gap 현재값 유지
주 비교 = 같은 홀드아웃 에피소드에 대한 B−A paired 차이 + 에피소드 단위 신뢰구간
```

### 결론 범위 — 넘지 않는다
> **시뮬 사전학습이 홀드아웃 실 시연의 상대 action chunk 예측 오차를 낮췄다.**

실물 작업 성공이나 시뮬 롤아웃 성공으로 확대 해석하지 않는다.
⚠️ 이 지표는 롤아웃이 아니다. val_loss 0.00547→0.00517 에 롤아웃 0% 였던 전례가 있다.

### 되돌릴 조건
- 홀드아웃 오차가 identity 기준보다 낮지 않으면 세 조건 모두 "학습이 안 됐다"로 읽는다
- 실물 로봇팔이 복구되면 롤아웃 기반 재측정으로 대체한다

## D-AI-53 · 실행가능성 게이트를 결과 모방 기준으로 재정의

**작성자**: 김준태(트랙 B) · **트랙 A 합의됨**

```
기존  시연 전체 궤적 연속 IK 수용률 ≥ 70%   → 19/65 = 29.2% 불통과
변경  파지 순간 정렬 · 파지 전후 ±0.8초 국소 IK → 533/535 = 99.6% 통과
```

**게이트 완화가 아니라 질문 교체다.** 제품 기조가 결과 모방인데
궤적 모방 기준으로 재고 있었다. 전체 궤적 29.2% 는 **"궤적 모방 난이도"** 로만 유효하고
폐기율도, 5자유도 병목의 근거도 아니다.

### 인용 제한 (트랙 A 명세)
99.6% 는 **단일 물체 배치에서 파지 전후 ±0.8초의 국소 IK 가능성**으로만 표기한다.
전체 접근 경로 · 다른 물체 배치 · 실물 실행 가능성까지 통과했다고 쓰지 않는다.

### 트랙 A recorded-oracle 14/14 와의 관계
같은 방향이지만 **같은 측정이 아니다. 합쳐서 인용하지 않는다.**
