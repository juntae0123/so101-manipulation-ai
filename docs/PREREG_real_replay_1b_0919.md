작성 김준태 · 2026-09-19 · **실행 전 작성** · 이슈 S15P21A103-35

D-AI-58 에 게이트는 박혀 있었으나 **재시도·안전중단·대상물이 빠져 있었다**
(황도경 지적). 빠진 것을 결과 보기 전에 채운다. **게이트 수치는 안 바꾼다.**

---

## 판정 가능한 성공 조건 (1회)

```
성공 = 물체가 책상에서 0.10 m 이상 올라가고, 그 상태를 0.5초 이상 유지
판정 = 영상 녹화 후 사후 판정. 실시간 눈대중 금지
```
시뮬 성공 기준과 **같은 문장**이다 (`lift > 0.10m` and `hold >= 0.5s`).
`lift_height 0.13` 은 IK 명령 목표이지 성공 기준이 아니다.

## 대상물 — D-AI-70 으로 바뀌었다

```
사용   실 시연 74편에 쓴 케이스 (닫힘 gap 중앙 38.5mm [32.4, 43.5] n=69)
금지   시뮬 YCB 캔 ⌀67.8mm — 배포 정책이 학습한 물체가 아니다
```
⚠️ D-AI-58 작성 시점에는 캔을 전제했다. **대상물이 바뀌었으므로
D-AI-58 의 예측(10~15/20)은 참조집단이 달라졌다.** 아래 §예측에서 다시 적는다.

## 초기 배치

```

허용오차  자로 재서 놓는 오차 ±5mm 규모 — 이건 갭이 아니라 우리 측정오차다.
          잰 값과 오차 추정을 기록에 같이 남긴다
자세      케이스 장변이 로봇 접근축과 이루는 각을 기록한다. 매회 같게 놓는다
조건      카메라 시야 안 · 도달영역 안 (D-AI-67 — 폐루프에 필요한 건 이것뿐)
```

## 재시도 — 허용하지 않는다

```
1회 = 1시행. 실패해도 그 시행은 분모에 남는다
같은 시행 안에서의 재파지(정책이 놓쳤다가 다시 잡는 것)는 허용. 시간 제한 안이면 성공
사람이 물체를 고쳐 놓거나 로봇을 손으로 도우면 그 시행은 **실패**로 센다
```
**재시도를 허용하면 분모가 사라진다.** 20회는 20회다.

## 안전 중단 — 분모에 포함한다. 단 사유별로 따로 센다

```
분모      20 (고정)
분자      성공한 시행 수
별도 집계  safety_stop_n · 사유별 내역
```
안전 중단을 분모에서 빼면 **위험한 실행일수록 성공률이 올라간다.** 그건 계측기가 아니다.

다만 사유가 **로봇 성능과 무관한 것**(전원, 통신 두절, 사람이 작업영역에 들어옴)일
때는 그 시행을 **무효로 하고 같은 조건으로 1회 추가 시행**한다. 무효 처리한 횟수와
사유를 전부 기록하고, 무효가 3회를 넘으면 **그날 측정을 버린다** (조건이 불안정한 것).
