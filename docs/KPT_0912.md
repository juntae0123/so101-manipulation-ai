## Problem

- **어시스턴트 오류 — `SCALE_CORRECTION` 을 n=1 에 적합하고 같은 n=1 로 검정했다.**
  단일 편 fixture 0.348mm 통과 → 71편 전수 1.26mm. 그 편 비율 1.005, 전체 중앙 1.027.
  오전에 "틀린 답에도 통과하는 검사는 검사가 아니다"를 적어놓고 같은 날 반복했다
- **어시스턴트 오류 — 손목 전용 효과를 n=3 으로 보고했다.** +26.0%p 로 냈는데
  시드 3·4 를 더하니 5시드 합산 약 +18%p 로 내려간다. 프로젝트가 이미 "실행 간 25%p"
  를 경고하고 있었는데 3시드로 덮으려 했다. **정정 필요 (아래 Try)**
- **어시스턴트 오류 — `git add` 를 세 경로 한 번에 줬다.** `AI/queue/LEDGER.md` 가
  없어서 통째로 실패했고 커밋이 "no changes added" 로 끝났다. git add 는 부분 실패가 없다
- **어시스턴트 오류 — argparse 도움말에 `%p` 를 썼다.** `--help` 가 터졌다.
  `%` 는 `%%` 로 쓴다
- **어시스턴트 오류 — 서버에 데이터가 있는지 확인하지 않고 잡을 세 번 띄웠다.**
  프레임 없음 → tgz 미업로드 → 또 미업로드. 사용자가 같은 실패를 3회 붙여넣었다.
  블록을 줄 때 가드를 먼저 넣었어야 했다
- **왕복이 너무 많았다.** 명령을 한 번에 한 줄씩 줘서 사용자가 명시적으로 지적했다
- 폐쇄량 프로브 잡이 `f=0.50` 에서 끊겼다. JSON·EXP_LOG 미기록 → 재실행 필요
