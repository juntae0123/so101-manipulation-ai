# PREREG — 폐쇄량 상한이 파지 성공률에 미치는 영향

- 일자 2026-09-12 · 작성 김준태(트랙 B) · 이슈 S15P21A103-34
- 도구 `AI/tools/probe_gripper_closure.py`
- **결과를 보기 전에 작성한다.** 실행 후 이 문서를 고치지 않는다.

---

## 1. 왜 재는가

0911 실수집 71편에서 그리퍼가 끝까지 닫히지 않는 것이 두 경로로 확인됐다 🟢.

- 마커 실측: gap < 30mm 가 5,759프레임 중 5개(0.09%) · 편별 최소 gap 중앙 37.26mm
- 계약 변환본: `action[:,5]` 최솟값 −0.2922 (닫힘 −1.0) → 개방→닫힘의 **약 35% 지점**

이걸 근거로 HW·PM 에 재수집을 요청하고 있는데, **"38~40mm 면 못 잡는다"는 논증이지
측정이 아니다.** 시뮬에서는 잴 수 있으므로 잰다.

## 2. 무엇을 재는가

천장 정책(`ScriptedPickPolicy`)의 **그리퍼 채널 명령에만** 바닥값을 걸고 성공률을 본다.
나머지 5채널은 건드리지 않는다 — 팔은 똑같이 움직이고 턱만 덜 닫힌다.
팔까지 바꾸면 원인을 못 가른다.

바닥값은 하드코딩하지 않는다. pass 0 에서 scripted 가 실제로 낸 명령의
최대(개방)·최소(폐쇄)를 관측해 그 사이를 비율 `f` 로 자른다.
관절 범위는 `configs/` 에 있고 로봇이 변형 예정이라, 상수를 박으면 조용히 틀린다.

**재는 폐쇄량 (착수 전 확정, 결과 보고 늘리지 않는다):**

```
f = 1.00, 0.80, 0.60, 0.50, 0.40, 0.35, 0.20
```

`f = 0.35` 가 실수집 관측치다. 나머지는 그 주변 기울기를 보기 위한 것이다.
목록을 사후에 늘리면 그것은 다중비교다.

## 3. 조건

| | 값 |
|---|---|
| 시뮬 | MuJoCo 3.12.0 · EGL 헤드리스 · render=False |
| 물체 | 2cm 20g 큐브 · xy 지터 ±50mm (기존 baseline 과 동일) |
| n | **100** · 시드 1000~1099 · 모든 조건이 동일 시드 |
| 정책 | scripted (천장). 학습 없음 |

n=100 인 이유: n=20 은 95% 구간 반폭이 약 ±18%p 라 게이트 폭과 같다.
게이트를 옮기는 대신 n 을 올린다.

## 4. 계측기 검정 — 먼저 통과해야 한다

`f = 1.00` 은 상한을 걸지 않은 pass 0 과 **성공 시드 집합이 정확히 일치**해야 한다.

다르면 래퍼가 그리퍼 외 채널을 건드렸거나 바닥값 계산이 틀린 것이고,
**그 실행의 모든 수치는 무효다.** 도구가 `rc=1` 로 끝난다.

0912 오전에 「틀린 답에도 통과하는 검사는 검사가 아니다」를 겪었고,
같은 날 「n=1 에 맞춘 상수를 같은 n=1 로 검정」하는 실수를 또 했다.
그래서 이 검정은 조건 목록 안에 넣어 매 실행마다 돌게 한다.

## 5. 판정 기준 (결과 보기 전 확정)

`f = 0.35` 성공률 기준:

| 관측 | 판정 |
|---|---|
| **< 10%** | 재수집 필수 판정의 근거가 된다 |
| **10 ~ 50%** | 판정 보류. 대상물 실측 폭 확인이 먼저다 |
| **>= 50%** | **내 에스컬레이션이 과했다.** 그대로 기록한다 |

세 번째 줄을 넣는 이유는, 이 실험이 내 주장을 지지하는 쪽으로만 읽히면
그것은 측정이 아니기 때문이다. 기준을 실행 후에 옮기지 않는다.

## 6. 이 실험이 답하지 않는 것

- **실물에서 같은 f 가 같은 결과를 내는지** — 답하지 않는다.
  시뮬 성공률은 sim2real 갭의 **하한**이다. 여기서 무너지면 실물에서도 무너지지만,
  버틴다고 실물을 보장하지 않는다
- **대상물이 실제로 몇 mm 인지** — 답하지 않는다. HW 실측이 필요하다
- **다른 물체 크기·형상에서의 결과** — 2cm 큐브 한 종뿐이다

## 7. 예측 (기록용)

f=0.35 에서 성공률 **0~5%** 로 예측한다 🟡. 2cm 큐브를 개구 35% 지점에서 놓으면
턱이 물체에 닿기 전에 멈추므로 파지 자체가 성립하지 않는다고 본다.

예측이 빗나가면 그것도 기록한다 — 0912 에 손목 전용 성능을 −8~18%p 로 예측했다가
실제 +26.0%p 가 나온 전례가 있다 (L77).
